# English-to-French Neural Machine Translation using PyTorch

## Project Overview
This project demonstrates a basic English-to-French neural machine translation system using PyTorch and a Sequence-to-Sequence (Seq2Seq) architecture.

## Dataset
A small custom dataset containing English and French sentence pairs.

## Technologies Used
- Python
- PyTorch
- NumPy
- Google Colab
- LSTM
- Seq2Seq Encoder-Decoder

## Project Workflow
1. Build English and French vocabularies.
2. Tokenize sentences into numerical sequences.
3. Add SOS and EOS tokens.
4. Apply padding to sequences.
5. Create a custom PyTorch TranslationDataset.
6. Load training batches using DataLoader.
7. Build an LSTM Encoder-Decoder model.
8. Train and evaluate the translation model.

## Model Architecture
Sequence-to-Sequence (Seq2Seq) using LSTM Encoder and Decoder.

## Learning Objectives
- Understand vocabulary building and tokenization.
- Learn sequence padding and special tokens.
- Understand PyTorch Dataset and DataLoader.
- Implement neural machine translation.

## Future Improvements
